Access for everyone

Website accessibility

We want everyone to be able to learn about Gather & Thrive and get in touch.

Our accessibility target is the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA, alongside the applicable web requirements of the Revised Section 508 Standards. This is an ongoing commitment, not a claim of independent certification.

Using this website

  • Use your keyboard to follow links and open the questions. A visible outline shows which item has focus.
  • The first keyboard link lets you skip the navigation and go directly to the main content.
  • Enlarge text or zoom using your browser. The layout adapts to narrow screens.
  • Headings and page landmarks help screen reader users move through the content. Photos have text descriptions.
  • There is no autoplaying audio, video, flashing content, or animation. The site works without JavaScript.

Tell us about an access barrier

If you have difficulty using this website or need information in another format, please email or write to us. Include the page or information you need, what did not work for you, and a way to reply.

Review and improvement

We review accessibility as the website changes. Keyboard, layout, and automated checks help identify barriers, but do not replace testing with people who use assistive technology. A complete independent conformance review has not yet been completed.
